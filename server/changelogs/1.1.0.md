# 1.1.0

- 一起听全面重构：
  - 昵称固定为网易云账号名，不可修改
  - 同步间隔缩短至 0.5 秒，漂移纠正阈值收紧，切歌同步更及时准确
  - 修复播放列表顺序错乱问题，跟随切歌不再打乱队列顺序
  - 修复成员有权限但无法切歌、删歌、编辑列表的问题
  - 获权成员操作时像房主一样广播给全员，而不是被强制跟随
  - 播放模式同步：随机 / 顺序、单曲循环 / 列表循环随房主同步
  - 无权限成员强制跟随房主歌曲，无法擅自切换
  - 加载失败不再无限跳歌，同时防止因失败而脱离同步
  - 修复移交房主后旧房主无法播放新歌的问题
  - 权限支持逐成员单独设置，服务器保存 per-member 覆盖
  - 房间解散时通知所有成员优雅退出
- 更新日志改为由服务器按版本提供
- WebUI 登录改用 Cookie（24 小时过期、HttpOnly）
