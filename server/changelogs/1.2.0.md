# 1.2.0

- 服务器支持自更新：从 GitHub 最新 release 拉取 `server.py` / `webui.py` / `requirements.txt`
- 新增 `config.yml` 的 `update` 配置段（`enabled` / `github_repo` / `github_token` / `check_interval_minutes`）
- 新增公开接口 `GET /api/version`，返回当前版本与是否有待安装更新
- 新增管理接口：更新状态、立即检查、下载并安装、重启服务器、查看更新日志
- 更新前校验下载文件（非空、Python 语法可编译、版本号与 release 一致、依赖行可识别）
- 替换前自动备份旧文件到 `backups/<旧版本>-<时间戳>/`，安装完成后自动重启
- 待安装状态持久化到 `update-state.json`，服务器重启后仍可继续安装
- WebUI 管理后台新增「服务器更新」面板：检查 / 下载并安装 / 重启 / 查看更新日志
